Last week there were a lot less drawings. Why?

Well, one of the possible reasons is that yesterday **we found a critical bug on Safari** which prevent from loading javascript libraries therefore nothing on the page was working, pixel editor: KO, pagination: KO.  
 Draw! was simply broken on Safari browser and so on every iDevice.

We want to apologize for this misbehaviour and to tell that **we fixed the bug and now everything is working as expected**.

Moreover we fixed an old bug affecting Facebook auth process on canvas app.  
Now if you’re a returning Draw! user and you’re accessing Draw! from Facebook canvas while authenticated on Facebook you’ll be recognized also by Draw! seamlessly.

If you find bugs or want to give us feedback put them on https://github.com/potomak/drawbang/issues or mention Draw! [@drawbang](http://twitter.com/drawbang)

Now stop worrying about tech stuff, just draw some pixel art at [http://drawbang.com](http://drawbang.com) and have fun!
